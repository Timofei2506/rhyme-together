# Как добавить свою песню (караоке)

Пайплайн рассчитан на то, что вы кладёте в репозиторий **свои** треки:
mp3 и текст с таймингом. Из них собирается всё, что нужно игре.

## Быстрый путь

```bash
# 1. минус + текст → стемы и партитура
python3 tools/karakoke.py моя_песня.mp3 моя_песня.txt my_song_id

#    если есть отдельный минус (лучший вариант):
python3 tools/karakoke.py моя_песня.mp3 моя_песня.txt my_song_id --minus минус.mp3

# 2. пересобрать индекс и модуль для сервера
python3 tools/build_song_index.py

# 3. выложить
npm run deploy:cf
```

После этого песня появляется в библиотеке, в списке выбора в комнате и
в случайном выборе на сервере.

## Что получится

```
src/data/songs/my_song_id.json      ← партитура: текст, слоги, ноты, тайминг
src/data/audio/my_song_id/
    instrumental.mp3                ← минус
    guideA.mp3                      ← вспомогательный вокал партии A
    guideB.mp3                      ← вспомогательный вокал партии B
    spectrogram.png                 ← картинка «волна + спектр» для проверки тайминга
```

Приложение играет **настоящие файлы**, если у песни есть поле `audio`.
Демо-песни без файлов синтезируются из партитуры — это работает, но звучит как
синтезатор.

## Формат текста

Обычный `.txt`, см. `docs/example-lyrics.txt`:

```
#title: Название
#artist: Исполнитель
#bpm: 96
#beats: 4
#tonic: 57
#key: minor

[0:12.4] Пер-ва-я стро-ка пар-тии А
| [0:12.4] От-вет-на-я стро-ка пар-тии Б
```

* `[мм:сс.д]` — момент начала строки, обязателен;
* строки без префикса — партия A, с `|` — партия B;
* дефис разделяет слоги (по ним идёт подсветка), пробел — слова.

## Если минуса нет

Без `--minus` конвертер вычитает центр стерео (там обычно вокал).
Это работает как в бытовых караоке-машинах: голос уходит, инструментал остаётся.
Если вокал записан не по центру или сильно обработан, вычитание будет неполным —
в таком случае лучше использовать готовый минус.

## Проверка тайминга

Откройте `spectrogram.png` рядом с текстом: видно, где вступает вокал.
Если строки съезжают — поправьте время в `.txt` и запустите конвертер снова.

## Лицензия и права

В репозиторий кладите только то, на что у вас есть права: свои треки или
материал с лицензией, разрешающей использование и переработку (CC BY, CC BY-SA и т.п.).
Пиратские караоке-треки в публичном репозитории — это риск не для сервиса,
а лично для владельца аккаунта: жалоба правообладателя бьёт по владельцу.

## Обновляется ли сайт само

См. раздел «Деплой» в README. Коротко:

* **изменения только в `src/` и `worker/`** — нужен `npm run deploy:cf`
  (или пуш в main, если включён GitHub Actions с секретом `CLOUDFLARE_API_TOKEN`);
* **Cloudflare Workers Builds** (авто-деплой прямо из панели Cloudflare) —
  включается в панели: Worker → Settings → Builds → Connect репозиторий;
  API-токен этого сделать не даёт, только панель.
